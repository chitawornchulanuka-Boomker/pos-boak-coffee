# ☕ BOAK COFFEE - ระบบ POS บัญชีรายรับ-รายจ่าย & สต็อกรายเดือน
### ออกแบบเฉพาะสำหรับแท็บเล็ตและผู้ใช้งานวัย 50 ปีขึ้นไป (Offline-First PWA)

ระบบจัดการร้านกาแฟที่บ้านที่เน้น **"ความง่าย สบายตา ตัวหนังสือใหญ่ ปุ่มใหญ่ ไม่ต้องเพ่งเล็ง และไม่ซับซ้อน"** บันทึกข้อมูลแบบออฟไลน์ 100% ใช้งานได้แม้ไม่มีสัญญาณอินเทอร์เน็ต

---

## 🌟 ฟังก์ชันหลักของระบบ

### 1. ☕ ขายหน้าร้าน (POS)
- เมนูเป็นการ์ดขนาดใหญ่ แตะเลือกเครื่องดื่มลงตะกร้าง่าย
- ปุ่มปรับเพิ่ม-ลดแก้วขนาดใหญ่
- **ระบบคิดเงินอัตโนมัติ:**
  - 💵 **เงินสด:** มีปุ่มลัดธนบัตร (100, 500, 1000, พอดี) คำนวณเงินทอนให้อัตโนมัติด้วยตัวหนังสือสีเขียวตัวใหญ่
  - 📱 **สแกนจ่าย QR (พร้อมเพย์):** ดึงยอดเงินจากบิลสร้าง QR Code เต็มหน้าจอให้ลูกค้าสแกนได้ทันที ไม่ต้องให้ลูกค้าพิมพ์ยอดเอง
- เสียงเตือน "ปิ๊ง!" และเครื่องหมายติ๊กถูกสีเขียวขนาดยักษ์ยืนยันเมื่อบันทึกการขายสำเร็จ

### 2. 💸 บันทึกรายจ่าย (ต้นทุนร้าน)
- แยกหมวดหมู่สีสันชัดเจน:
  - ☕ **เมล็ดกาแฟ**
  - 🥛 **นม / ไซรัป / ส่วนผสม**
  - 🥤 **แก้ว / ฝา / บรรจุภัณฑ์**
  - 🧊 **น้ำแข็ง / ของสด**
  - 💡 **ค่าน้ำ / ค่าไฟ / ค่าแก๊ส**
  - 📦 **ของใช้จิปาถะ / อื่นๆ**
- **แป้นตัวเลขขนาดใหญ่ (Big Touch Numpad) บนหน้าจอ:** สัมผัสง่าย ไม่ต้องง้อแป้นพิมพ์ระบบที่ตัวเล็ก
- มีปุ่มลัดคำอธิบายด่วน เช่น `+ ซื้อแม็คโคร`, `+ ซื้อโลตัส`, `+ ตลาดสด`

### 3. 📦 สต็อก & สรุปยอดใช้จริงรายเดือน (Monthly Inventory & Usages)
- ออกแบบตามวิถีร้านกาแฟที่แท้จริง ไม่ต้องเสียเวลานั่งชั่งตวงกรัมทุกแก้วที่ขาย
- **สูตรคำนวณ:** `ยอดใช้ไป (Usages) = ยกมาต้นเดือน + ซื้อเพิ่ม - ของเหลือนับจริงสิ้นเดือน`
- คำนวณต้นทุนวัตถุดิบจริงประจำเดือน (Cost of Goods Sold)
- มีระบบรับของเข้าสต็อก พร้อมตัวเลือกบันทึกลงในรายจ่ายร้านอัตโนมัติในคลิกเดียว

### 4. 📊 สรุปยอดบัญชี & กำไรสุทธิ (Dashboard)
- 3 การ์ดยักษ์ด้านบนสุด: **🟢 เงินเข้า (ยอดขาย) | 🔴 เงินออก (รายจ่าย) | 💰 กำไรสุทธิ**
- สลับดูได้ทั้ง **"วันนี้"**, **"เดือนนี้"** และ **"ยอดรวมทั้งหมด"**
- สรุปช่องทางรับเงิน (เงินสด vs สแกน QR)
- 5 อันดับเมนูขายดีประจำร้าน
- **ปุ่มเด็ด:**
  - **"📋 คัดลอกสรุปส่ง LINE"** คัดลอกสรุปยอดพร้อมอีโมจิสวยงาม นำไปวางส่งในไลน์ได้ทันที
  - **"📥 โหลด Excel (CSV)"** ดาวน์โหลดไฟล์รายรับ-รายจ่ายไปเปิดดูบนคอมพิวเตอร์

### 5. ⚙️ จัดการร้าน & สำรองข้อมูล (Settings)
- ตั้งชื่อร้าน และเปลี่ยนเบอร์ PromptPay สำหรับแสดง QR Code
- เพิ่ม/แก้ไข/ลบ เมนูกาแฟ และปรับราคาขาย
- **ระบบสำรองข้อมูล (Backup to JSON):** ดาวน์โหลดเก็บไว้ ข้อมูลไม่มีวันหายแม้เปลี่ยนเครื่อง
- **ระบบกู้คืนข้อมูล (Restore):** ดึงข้อมูลกลับมาได้ทุกเมื่อ

## 🚀 วิธีเปิดใช้งาน

### 1. รันระบบในเครื่อง (คอมพิวเตอร์ / เครื่องแม่ข่าย)
เปิด Terminal ในโฟลเดอร์นี้ แล้วพิมพ์:
```bash
npm run dev
```
ระบบจะแสดง URL เช่น `http://localhost:3000` หรือ `http://192.168.x.x:3000`

### 2. วิธีเปิดบนแท็บเล็ต (iPad หรือ Android Tablet)
1. ให้แท็บเล็ตและคอมพิวเตอร์เชื่อมต่อ Wi-Fi บ้านเดียวกัน
2. เปิดเบราว์เซอร์บนแท็บเล็ต (Safari บน iPad หรือ Chrome บน Android)
3. พิมพ์หมายเลข IP ตามที่แสดงใน Terminal เช่น `http://192.168.1.50:3000`
4. **ติดตั้งเป็นแอปบนหน้าจอโฮม (Full Screen App):**
   - **บน iPad (Safari):** กดปุ่มแชร์ (สี่เหลี่ยมลูกศรชี้ขึ้น) -> เลือก **"เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)**
   - **บน Android (Chrome):** กดจุด 3 จุดมุมขวาบน -> เลือก **"ติดตั้งแอป" (Install App)**
5. เมื่อแตะไอคอน BOAK POS บนหน้าจอโฮม จะเปิดเต็มหน้าจอเหมือนแอปจริง ไม่มีแถบเบราว์เซอร์มากวนใจ และใช้งานออฟไลน์ได้ 100%!
